Actividades de práctica

Resuelve primero en tu cuaderno y utiliza este laboratorio para comprobar tus respuestas. Registra las ecuaciones, justifica tus conclusiones y guarda una captura cuando se solicite.

  1. Directriz y generatrices. Selecciona el cilindro circular con radio 2. Identifica la directriz en z = 0 y escribe la ecuación vectorial de la generatriz que pasa por (2,0,0). Comprueba con la app.
  2. De círculo a elipse. Selecciona el cilindro elíptico, fija a = 2 y b = 3. Cambia b a 2. Describe qué cambia y qué permanece igual. Guarda una imagen de cada caso.
  3. Trazas. En el cilindro circular de radio 2, compara z = 0, z = 3, x = 0, x = 2 y x = 3. Predice si la intersección es una circunferencia, dos rectas, una recta o el conjunto vacío. Verifica con la app.
  4. Cilindro parabólico. Usa k = 1 y después k = 0.5. Identifica la variable ausente, la dirección de las generatrices y las trazas y = 0 e y = 2. Explica el cambio de apertura.
  5. Cilindro hiperbólico. Usa a = b = 2. Compara las trazas z = 0, x = 0 y x = 3. Escribe sus ecuaciones y comprueba tus bosquejos.
  6. Más allá de las cónicas. Selecciona el cilindro sinusoidal. Cambia A de 1 a 2 y b de 1 a 2. Describe cómo cambian amplitud y período y explica por qué sigue siendo un cilindro.
