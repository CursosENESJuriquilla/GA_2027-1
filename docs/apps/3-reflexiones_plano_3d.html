Construcción geométrica

H es el punto medio de PP′PP′ ⟂ ΠEl plano queda fijoConserva distancias

El vector normal n determina la dirección perpendicular al plano. Primero proyectamos P sobre Π para encontrar H. Después prolongamos el segmento PH la misma distancia al otro lado del plano, obteniendo P′.

H = P − [(n·P − d)/(n·n)] n P′ = 2H − P

Para discutir en clase

¿Qué sucede si P pertenece al plano? ¿Qué puntos permanecen fijos? ¿Por qué H es el punto medio de PP′? ¿Qué cambia al multiplicar simultáneamente a, b, c y d por un mismo número distinto de cero?

La aplicación representa una reflexión activa: se mueve el punto, pero los ejes x, y, z no cambian.
